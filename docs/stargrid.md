# 灰阶菱格 · 旋转星芒

Composition: `stargrid`，720×1280，30fps，11秒。

前10秒按参考节奏旋转两圈，后1秒定格。两颗六角星芒的中心和尺度始终固定，曲线为 cubic-bezier(0.3,0,0.3,1)。参考画面的网格没有滚动或缩放。

## 可编辑

修改 `src/shots.json` 的 `stargrid.scene.props`：配色、星芒尺寸与位置、旋转时间和圈数、网格间距与线宽、光晕与阴影。`showStars`、`showGrid`、`showBaseFill` 可分别控制各层。`width` / `height` 位于该镜头的顶层配置。

## 实现与验收

矢量轮廓位于 `src/kit/components/star-grid-reference.json`，从用户提供的参考逐帧轮廓拟合得到，渲染不引用原视频。核心组件 `StarGridBackdrop.tsx` 可单独导入。颜色是参考专用灰阶参数，与品牌暖色系统分离。

- 原参考301帧；成品330帧（含额外终态）。
- 六个关键帧的两颗星芒轮廓重合度约97%–98%。
- 300、303、329帧的无损渲染哈希一致，验证停止后没有几何漂移。
- 完整视频解码、类型检查、composition注册、参数开关检查通过。

边界：灰阶光场、网格渐隐与柔阴影为参数化重建，压缩纹理没有逐像素复制。素材本身无搜索框或文字；文件名称不代表画面内容。成品为静音背景，不含原参考音轨。
