# 计算工作量 · 时钟与大数字

时钟描边先出现，随后177,000 Tokens从大到小落定。可替换数值、单位、背景图和颜色。背景使用原片静态底图，时钟与数字程序重建；背景行情与镜头细微变化为近似，未复原原声及字幕。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

修改 props.json 的文字、数值、颜色、素材路径及时长。不同字数请留意画面边界。默认时长与参考一致。静态素材来自用户的 Eagle 参考，仅复刻代码按仓库许可发布，素材仍须遵守其原始权利。

发布包不分发本机字体。默认尝试已安装的宋体与阿里巴巴普惠体，缺失时回退到系统字体，字形和字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
