# AI 三要素 · 轨道节点轮转

中心网络球出现，三条连线与节点展开，整体轨道缓慢旋转并交替强调算力和数据。位置、节点角度及入场按源帧测量；中心多面体和背景噪点采用程序近似。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。
