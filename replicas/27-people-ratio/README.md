# 人数结构 · 双组图标累积

依据源 F0–134 重建双组头像阵列的逐项入场、分组标题、计数与出场。84个图标的位置按源帧追踪；默认数字、标签、颜色、时长可改。头像单元为参考静帧提取的透明蒙版，页面噪点、中文字体和透视插值保留近似说明。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。每组 color 控制数字与标记，iconColor 控制头像色彩。图标数量随 value 变化，数字使用源静帧提取的 0–9 字形组合。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

发布包不分发本机字体。默认尝试已安装的宋体与阿里巴巴普惠体，缺失时回退到系统字体，字形和字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
