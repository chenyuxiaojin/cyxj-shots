# 院校分布 · 气泡错帧生长

81 帧 / 30 fps / 1920×1080。九个气泡由微点依次长大，名称和数字展开，保持最终状态。默认显示原片示例数据。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

修改 `props.json` 的标题、注释、来源说明、9组标签/数值、气泡颜色、背景叠色和时长。数值改变时按面积比例重新计算半径并维持总宽度。小圆标签可以用 `\n` 分行。默认数值保留逐帧测得的椭圆与位置。

默认渲染：`preview/preview.mp4`。替换参数示例：`docs/variant.json` 与 `docs/variant.mp4`（改文字、数据、橙色、4秒）。

## 几何与来源

`src/tracks.json` 保存源F0–80每个圆的几何，`src/geometry.ts` 插值，`docs/keyframes.md` 记录每个元素的起始/可见/锁定帧。源帧号直接对应 `docs/frames/fXXXX.jpg`。先渲染 `Trace` 对照，再实现 `Replica`。几何在各自锁定帧后不再变化。

原片的九个圆没有持续透视旋转；标题单独下落，入场圆心微移来自测量。颗粒与字形并非摄影机运动。

## 已知近似

中文使用本机已安装字体。数字优先使用本机 Bodoni 72，缺失时回落 Times New Roman 或本机宋体，跨系统字形会略有差异。数字字宽和比例按参考调整。文字短暂弹性与颗粒为程序近似。F0–6前镜残影使用从参考分离的静态贴片，退场轨迹近似。背景是清理字幕和水印后的静态参考图，保持构图与颜色；未重建原片逐帧颗粒。

核心气泡与所有信息文字均为原生可编辑 SVG，不用原视频充当动画。原声、字幕和水印未纳入。

原视频仅供本地对照，不应打包公开。静态参考资产的权利属于原权利人，代码许可不涵盖这些资产。

发布包不分发本机字体。默认尝试已安装的宋体与阿里巴巴普惠体，缺失时回退到系统字体，字形和字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
