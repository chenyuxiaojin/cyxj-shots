# 忠实度与素材边界

- 默认显示器和屏幕画面为原片 F0 的局部静态截图（只裁显示器区域，不是完整帧），用源帧实测整体轨迹重建缩放和位置。屏幕内容在抽查帧中基本相同；原片压缩/细微光影不逐像素重演。
- 双轴箭头、长度/宽度文字、总量计算、中心定位圈强化、斜向引线和标签揭示均为可编辑 SVG/React。没有通过播放原片伪装复刻。
- 背景暗网格、顶光和星尘用固定种子程序生成，微小颗粒位置与源片不同；没有带入原片字幕或作者水印。
- 尺寸标尺的短暂模糊淡入采用确定性透明度/模糊近似；文字使用本机已安装字体制作预览，公开包提供系统字体回退，跨机字形可能略有差别。
- durationSeconds 可改变总时长；screenSrc 可替换屏幕，monitorSrc 可替换整机静态图；数值标签和单位全可编辑。
- 原始 Eagle 媒体只读保留。公开包不含原片、整帧、对照视频和字体文件。显示器局部参考图版权归原权利人，仅供动效参考，发布商用时替换为有权使用的产品图。
