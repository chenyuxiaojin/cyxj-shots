# 逐帧 Trace 与几何表

坐标基准 960×540，最终渲染 1920×1080。源 F0–120 / 30 fps。先量出画面轨迹，再用同一几何数据驱动 Trace 和 Replica。

前屏用 F15 的 300 个局部特征作逐帧光流跟踪，并用 RANSAC 单应矩阵复核。后五层扫描连续右边缘，配合公共纵深投影。后层首次露出的 1–2 px 窄缝采用相邻层延迟插值。源视频只在 Trace 中播放。

## 几何收束边界

未设置早于 F120 的 lockFrame。F90→120 仍保留源前屏约 0.3 px 的纵向微移及后层约 0.5 px 的深度收束。整个复刻都按源帧序号连续插值，时长变体将 F0–120 映射到新的总帧数。

## 近似与来源

- 屏幕素材为源 F15 无字幕、无指示标注的局部四角透视矫正静帧（614×410）；默认六层使用同一游戏截图，可逐层换图。图像内部的游戏像素变化未重做，所有屏幕的空间运动是独立重建。
- 开头机壳是静态材质外观，随前屏平移并按实测透明度退场。来源同批原片的干净显示器局部，已复制到本包，不依赖兄弟目录运行。
- 片头数字标注重建为可编辑文字和 SVG 引线。源片字体和柔光做近似。
- 黑色网格、顶部雾光和星点程序重建；网格间距按原片测为约 20.8 px，粒子位置非逐点复现。
- 后层使用同一透视深度列，早期 Y 方向角点存在数 px 近似；右边缘 X 由逐帧测量约束。
- 原片的字幕、右上水印仅保留在对照中；不会作为复刻元素。
