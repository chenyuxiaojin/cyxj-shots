# 还原边界

圆心、半径、镜头推近/右移/缩小和文字出现顺序据源片逐帧观察。源片圆边缘检测存在约1–3px量化噪声，已平滑；初始微点与小圆入场用关键帧插值。大圆和小圆在源片不是严格的面积比例（原设计比例照录）；替换数值时会按两组数值比相对原比值的平方根调整对照圆半径，主圆维持锚点，保持整体构图。

背景使用不含桌面图标、字幕、水印的天空局部裁图保留中央云层原坐标、羽化融合至外侧重构背景，边缘云朵与原片存在差别；天空推近为确定性近似。原片字体与短时透视抖动为近似，Tiny企鹅和电脑图标采用程序简化。主体圆弧、所有标签与文字均为可编辑SVG；没有播放原片替代动画。

默认数量和文案是原片的演示数据，不是本项目新做的数据调查。变体用明确的虚构服务/用户数据验证内容、数值、配色及8秒时长。
