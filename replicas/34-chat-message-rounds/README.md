# 聊天气泡 · 输入发送与三轮对话

按源聊天窗口F18–522（本地F0–504）复刻输入打字、发送轨迹和左右三轮对话累积。六条消息、两张头像、颜色和总时长可编辑；原片演示文案保留。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。


## 编辑参数

- `messages` 的六个槽位对应源片六条气泡；可改中英文、气泡宽高、字体大小和英文行宽。`at` 将该气泡及对应输入阶段前后平移，总时长按 `durationSeconds` 整体缩放。
- `avatars` 两项为可替换的图片/SVG路径；同一右侧头像用于两轮发言。
- 可改 `bubbleColor`、`buttonColor`、`textColor`、输入颜色，以及 `backgroundImage`、背景染色及透明度。
- `docs/variant.json` 是虚构日常对话示例，使用两张自绘头像、不同配色及20.5秒时长。

默认保留参考片可见聊天措辞（含英文原始拼写）。原水印、字幕、配音不进入模板。纸面底图与头像是静态参考分层素材；文字、气泡、控件和运动由原生元素绘制。

几何、逐元素时序与近似说明见 `docs/keyframes.md`。`public/__reference.mp4` 仅供私有 Trace 对照，不属于公开发布内容。

编码通过 remotion.config.ts 固定为 PNG 中间帧与 BT.709，源片比较时统一矩阵与范围。请保留此配置文件。

发布包不分发本机字体。默认尝试已安装的宋体与阿里巴巴普惠体，缺失时回退到系统字体，字形和字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
