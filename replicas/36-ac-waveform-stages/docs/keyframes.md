## 解析关系

`phase = -3.082 + 2π F / 30`

`ac(x) = 272.35 - 71.3 cos(2π x / 429.2 - phase)`

`rectified(x) = 270.5 - abs(ac(x) - 270.5)`

`filtered(x) = 230.8 + 17.5 cos(2π x / 429.2 - phase)`

`regulated(x) = 250.4`

斜线 `x(y) = x@270 - 0.4405 (y - 270)`。解析函数从源绿色轮廓拟合。整流不是简单使用等高 `abs(cos)`；原片交流中心 272.35 与反射轴 270.5 有偏差，源码保留这一关系。

## 近似边界

主体波形、填充、三道斜窗、标题、坐标与字幕均原生绘制，未播放整幅参考或截图。纹理颗粒与细网格、斜线边缘的微小色散、字体压缩形态属于近似。参考右上角品牌水印省略。保留原片所示波形示意，不把示意图宣称为可用于电路设计的数值仿真。
