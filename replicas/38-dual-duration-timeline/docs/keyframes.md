全帧颜色组件：color-components.json。相机测量：camera-measurements.json。反解回基准坐标的条形与楼宇尺寸：native-tracks.json。最终曲线与锁定状态在 src/tracks.json、src/geometry.ts。Trace 使用同一几何矩阵叠加源片。

原生元素：所有标题、标签、数字、条形、虚线、网格、箭头、背景圆及其运动。唯一默认参考裁片为楼宇局部透明 PNG。变体使用自绘办公楼 SVG，并改为虚构设计项目、12周周期、两部门阶段、配色与15.5秒时长。

近似：字体字形、纸面细粒、弧形中文字间距、楼宇进入最初几帧的背景圆与层间透视。水印、烧录解说字幕及原声未纳入模板。参考措辞仅保留画面示例，不扩展为医学或政策结论。

色彩复核：几何抽帧JPEG在解码展示时有矩阵偏差，最终颜色不以其取样值为准。关键颜色从源视频直接解码的RGB24 PNG取样，并与BT.709编码后的预览逐像素核对，见color-check.json。字体加载并等待 document.fonts.ready 后挂载 SVG；动态前景 SVG 额外使用 key={f} 逐帧重建。仅等待字体不能消除 Chromium 在连续 CSS 矩阵变化后复用 SVG 文字布局的问题，逐帧重建经 F250–338 连续渲染验证可恢复与 still 一致的文字边界。

胶囊内部标签另有淡入：研究标签 F70–84、临床标签 F136–150；小宽度阶段仅微弱切片，避免在黄条刚出现时有突兀黑字。证据见 label-emergence.jpg。
