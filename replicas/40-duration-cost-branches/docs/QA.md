# QA

取色依据为 lossless source 直接解码的 RGB PNG，几何测量可使用 JPEG，但不以其偏移后的绿色/黄色为颜色依据。默认和变体都固定 BT.709、PNG 截图渲染、关闭缓存。左右对照统一 limited BT.709。

21 个关键帧覆盖日数圆盘增长、胶囊展开开始/中段/锁定、总费用计数结束、主卡移动、左支黑条及裁切进入、两段箭头尖增长、占比弧展开、右支计数和尾部停留。见 qa-part-1.jpg 至 qa-part-4.jpg。Trace 可逐帧检查，trace-180.png 展示形状测量。

可编辑性变体：90天虚构项目、120–240万元预算、40–80及80–160万元分支、35%与65%占比、蓝橙配色、15秒。全部原生信息，不存在烘焙文字图片或源视频播放。

最终核验状态以 verification.json 为准：默认360帧12秒、变体450帧15秒；tsc、validate_shot --decode、原Eagle/截取源/默认/变体/对照五个视频全文件解码，原Eagle与截取源和私有参考SHA。

已知近似：纸纹和网格局部明暗为程序生成；原字体未知，随包字体字形/字宽略异，动态数字的斜切/模糊近似；被白圆或裁切完全挡住的初始费用值用相同的实测相位补全。右侧66%对应约120°黄弧是源片原样，未擅自调整成数据图意义上的66%角度；角度与文本可分别编辑。
