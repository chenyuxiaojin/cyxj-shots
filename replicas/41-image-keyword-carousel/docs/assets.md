# 静态资产来源

venice.png 与 paris.png 是 Eagle MSSSLARNRTTWX 的 F20/F96 卡片区域静态裁切，仅作原片对照示例，不包含原片播放。默认照片内保留原有装饰与底部牌面像素；复刻渲染时牌面区域由原生不透明地点牌完整覆盖，显示的地点中英文为可编辑文字。替换照片即可换成自己的内容。mountain.svg 与 harbor.svg 为程序绘制的虚构场景，变体采用它们。

参考照片不在代码 MIT 许可内，公开工程不包含源视频、原声、参考字幕或本机字体。

照片与三边无文字背景条均直接从源视频 RGB PNG 裁切，避免几何 JPEG 的色彩偏差。背景条不包含信息主体、字幕或水印。
