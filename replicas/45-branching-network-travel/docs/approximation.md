# 近似范围

本镜头以原生 SVG 重建三维网络的二维投影。蓝色枢纽通过色域和距离变换量测；241 条灰色圆点观测轨迹来自逐帧检测与邻帧匹配，分支归属以已量测的光流节点确定。曲线、圆点、数字、讲解字幕均可编辑，没有播放参考视频或逐帧贴图。

主路径分三次于参考 F22、F83、F136 开始变蓝，约 F29、F90、F143 完整展开；端点随后亮起。尾段 F183–198 还有一条向下延伸的第四段路径，已保留；第4端点未亮起。视点沿网络向左穿行，参考中没有全镜头锁定保持段。低景深、色散、灰线曲率与小数字不是原始三维模型重算，因此存在近似；遮挡或低对比处补间并淡入淡出。部分细小、重叠或不可辨识数字使用稳定的可替换示例，不声称逐字识别全部背景数值。

讲解字幕按源片保留为可编辑文字，包括原片提及 DeepSeek 的句子，仅复现参考文案；变体使用虚构网络演示文案。源水印与原声不包含。公开包不分发本机字体，缺字时使用系统回退字体。
