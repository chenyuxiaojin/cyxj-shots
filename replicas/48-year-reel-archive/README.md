# 年份卷轴档案 · 逐字归拢与圆形开合

默认文字为源片演示。三段年份纵向卷动，淡邻年保留空间关系；档案说明从右侧逐字归拢，纸箱缩放入场，硬币连续旋转跳动，圆形遮罩完成首尾过场。核心信息原生可编辑，建筑/气球/纸箱使用有出处的局部静态素材；变体以虚构项目和程序插画验证。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

## 编辑与素材

默认 25 fps、335 帧、13.4 秒，原片帧映射为本地帧 +8。`docs/variant.json` 提供虚构内容、配色、原生插画与 16 秒时长的完整变体。

局部裁切出处、保留的品牌与小字、字体和近似范围详见 [素材说明](docs/assets.md)。[关键帧表](docs/keyframes.md) 记录轨迹与锁定时机。

发布包不分发本机字体。默认尝试已安装的宋体与阿里巴巴普惠体，缺失时回退到系统字体，字形和字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
