# 薄层曝光 · 遮罩与局部移除

默认内容沿用原片演示。固定透视块体上依次出现薄层覆盖、悬空双开口遮罩、垂直曝光光柱和两侧材料移除；左侧工序列表随当前步骤滚动，标注连线和右侧大字对应切换。全部为原生可编辑图层，源片具体技术表述不作独立核验。原片末尾仅切入下一工序标题，未补造后续加工动作。

```sh
npm ci
npm run dev
npm run check
npm run preview
```
