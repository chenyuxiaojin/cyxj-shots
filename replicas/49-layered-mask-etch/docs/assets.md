# 来源与近似边界

参考：Eagle `MROQRWAB0X3B6`，原片 F135–534，25 fps。本地帧 +135 对应原帧。默认中文技术表述来自参考示例，未独立核验。

Replica 全部为原生 SVG 和可编辑文字，不使用源视频播放、整幅截图或局部源图片。程序描摹的背景人物仅为静态轮廓；纸/桌面颗粒、雾光、光柱散射、侧面反射和具体字形是近似。形体的四角、相位、遮罩开口、涂层方向、两侧移除机制按源帧测量。原声与源水印不包含在复刻内；底部字幕用原生文字重建。

字体在本地渲染时使用本机字体，公开包不分发字体。修改 `props.json` 中步骤、标注、字幕、颜色、人物轮廓开关与时长；虚构变体替换全部技术文案、青色配色、背景线格并延长至19.2秒。
