# 素材与来源

本镜头的电池、Li 字形、汽车、手机、黄色检视镜、网格、字幕均为原生 SVG/React。没有用参考截图制作主体，也没有任何需分发的图片。

参考来源为用户 Eagle 素材 MROQJHVP400HO《原片｜电池寿命检测图标｜S063》，取原 F0–135。参考视频、直接解码帧和 Trace/对照仅用于本地核验，不进入公开包。几何与颜色观测来自该窗口；权利仍属于原作者。

本地可选字体 `public/media/Title.ttf`、`Sans.ttf`、`Serif.ttf` 只用于匹配预览，不公开分发。缺失时回退到本机 PingFang SC / Microsoft YaHei / sans-serif。字形可能不同，文字保持可编辑。

变体的包装盒、控制模块、QA 符号及虚构文案由代码绘制，不使用参考素材。
