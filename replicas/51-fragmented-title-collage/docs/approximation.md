# 复刻范围与近似

已按实际源帧重建：五字默认标题的独立 SVG 形状和最终比例；两侧先显露、中间补齐的灰度碎条时序；橙刷起止和扩展节奏；整体缓慢拉远；前景景深变化；原字幕内容与可关闭开关。

近似边界：

- 原来的折片/阴影可能来自插件；本版用原生 SVG 38×24 灰度遮罩和模糊重建，局部纤维及折片边缘不逐像素相同。原笔画并未整体大幅位移，因此未添加虚构的大幅坠落。
- 默认标题五字轮廓来自最终源画面的矢量化，原始字体文件未知；换成其他文案时使用系统宋体，形态不会保持原片字库的全部特征。
- 英文细花体是本机 Imperial Script 的近似，原字幕采用本机苹方/无衬线字体；不同机器字体回退会产生字形差异。包内无字体文件。
- 人物与桌面是少量局部静态抠图，原源背景纸纹不能完整分层，人物边缘与格线衔接有轻微近似。纸面格线和颗粒为原生生成；底部播放器杂边已移除。
- 全局相机由稳定特征点量测并平滑，前景虚焦、底部暗部和画面颗粒是程序近似。未使用整帧贴图或源视频播放替代默认动效。
- 变体为虚构协作计划，切换原生人物/桌面，可替换新标题、副标题、颜色与时长。
