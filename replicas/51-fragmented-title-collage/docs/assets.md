# 素材与字形来源

参考条目：Eagle `MUXUEB6EFRWST`。参考窗口为原片 F15–182，共 168 帧、30 fps；本包 local F0 对应原片 F15。原始视频和逐帧参考仅用于私下量测，不在公开包中分发。

默认稿仅有以下三个局部 RGBA 图像。它们没有原标题、英文副标题或字幕，没有任何整帧背景图或逐帧视频替身。裁切坐标按 1278×720 最终参考平面记录：

| 文件 | 区域与来源 | 使用方式 |
|---|---|---|
| `media/left-person.png` | 最终平面 bbox `(215,236)-(479,596)`；人物头部取 local F0（原 F15）经实测单应矩阵反投影到最终平面，衣服下半取 local F167（原 F182） | 多边形透明抠图，1.1 px 羽化；独立图层随实测相机变化 |
| `media/right-person.png` | 最终平面 bbox `(651,214)-(1149,649)`；干净头部取 local F0，身体与握笔手部取 local F167 | 多边形透明抠图；上身与下方手部使用不同虚焦，渐变衔接 |
| `media/desk-foreground.png` | 最终平面 bbox `(0,284)-(1278,720)`；local F167 的椅背、桌面、前景显示器，非连续矩形画面，主体区域外透明 | 多边形局部抠图；底部 7 px 播放器色边和指针以邻近桌面边缘延展清除；独立景深模糊 |

默认标题 `真正的引线` 的五字轮廓由参考最终帧的黑色字形逐字转成原生 SVG path，保留内孔，路径存于 `src/glyphs.json`。这是五个独立可调整的矢量形状，不是原标题位图，也不包含字体文件。`headline` 仍是可编辑字符串。

- `glyphMode: "matched"`：若所有字符都在上述五字字典中，按独立 SVG 字形排版；任何未包含的字符会让整个标题自动回退到系统宋体，避免混用字形。
- `glyphMode: "system"`：任意标题均用原生 SVG text 和本机 `Songti SC, SimSun, serif`。
- 英文副标题始终是可编辑 SVG text，使用本机 `Imperial Script, Snell Roundhand, cursive`。不同机器缺少这些花体时会用系统 cursive，仍能渲染但外形不同。未分发任何字体文件。

标题揭示用原生 SVG 灰度遮罩网格。`src/visibility.json` 是按反投影后笔画显露量测的 38×24 数值场，只有数值、没有图像。它适用于新文案，文字内容不绑定源帧。橙刷由数个透明度等级的矢量轮廓组成（`src/brush-paths.json`），颜色与水平揭示时序可编辑。矢量化后填补了原字形遮挡造成的缺口，避免换文案后留下原字轮廓；细纤维由固定种子生成。格纸、阴影、颗粒和镜头移动均由代码生成。

变体使用七字虚构标题 `一起创造新计划`，青色笔刷、蓝色细花体、暖纸色、原生 SVG 人物和桌面，时长 7.2 秒；不使用上述三个源图资产。

源静态插画和原始字形示例的权利属于原权利人，代码许可不授予这些素材的商业使用权。可在 `assetMode: "native"` 下使用代码生成的人物和桌面，或自行替换拥有使用权的素材。
