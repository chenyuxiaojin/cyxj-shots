# 资产、字体与近似边界

默认文字、数据与动作来自 Eagle 素材 `MSSUEUN8TI3XX`，作品标题“字更少，为什么反而更费 token？”（差评君）。当前参考窗口为该 Eagle 片段的原 F4–197，30 fps。默认内容仅作为源片动效演示。

`Replica` 不使用源视频、源截帧、裁切图片、外部图标或字体文件。九个词块、方法按钮、字幕、绿色标签、虚线边界、斜纹灰面板与全部阴影/纹理均由原生 HTML / SVG / CSS 绘制。`src/tracks.json` 仅包含测量后的数值轨迹。

字体使用本机字体栈：英文 Arial；中文 PingFang SC，回退 Microsoft YaHei / sans-serif；字幕沿用该无衬线字体栈并加粗。字体文件不随包分发。没有安装这些字体的设备会使用回退字体，字形和行宽可能略有差异。

近似范围：源片精确字体未确认；词块入场弹性曲线按关键帧近似；背景柔光纹理、按钮倒角和内阴影以原生效果近似。原片水印与原声音轨不复制。所有文字内容均可替换，默认窗口不补造“点击选中 BPE”。

变体使用虚构项目清单；替换九个词块、四种方法、绿色标签与所有字幕，改紫色/蓝灰配色，改为三列网格词块，延长至8.5秒。

内部测量目录与 `Trace` 参考视频属于私有对照材料，不是复刻依赖，也不作为公开包资产分发。公开包仅需源码、JSON 参数和正常 npm 依赖。
