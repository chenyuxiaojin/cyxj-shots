# 清单反转 · 未兑现的一项

一张 9:16 清单逐项勾选，失败项放大并上移。标题白板随之扩张，遮住其余清单；失败符号进入白区后倒色，底部结论浮现，右下斜面开始进入。

全部文字、框、勾叉、白板、字幕与斜面均为原生 SVG 可编辑元素。默认对照原片 720×1280、30 fps，202 帧（6.733 秒）。没有整帧视频替身或图片背景。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 `props.json` 修改 `heading`、四个 `items`、`failedIndex`（0–3）、两行结论、配色、字幕内容或 `showCaptions`、`durationSeconds`。所选失败项会沿独立路径进入白区。`docs/variant.json` 提供虚构项目文案、第二项失败、紫色配色、关闭字幕、8.4 秒的完整渲染变体。

几何与节拍见 `src/tracks.json` 和 `docs/keyframes.md`，`Trace` 为私有源帧叠加测量入口。标题底板在本地 F129 后固定，失败框的微动和末尾结论移动仍继续。末尾只有右下斜面进入，上半白板不会随之旋转。

默认英文使用系统 Arial / Helvetica。可选本地中文字幕字体加载失败会回退系统字体；公开包不分发本机字体、原始视频或源帧。水印不复刻。字体、字距及源压缩/运动模糊为明确近似，详见 `docs/approximation.md` 和 `docs/assets.md`。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
