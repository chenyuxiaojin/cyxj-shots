# 素材与字体

本镜头的全部主体为原生 SVG：标题底板、文字、四个框、勾叉、结论、斜面和字幕。没有图片资产，没有源整帧背景，没有播放源视频冒充复刻。

私有调试文件 `public/__reference.mp4` 仅供 Trace 叠加核对。公开包应移除它、`docs/rgb`、原始帧及私有视频。来源 Eagle ID：MRPU3YOYLXTWG，原窗口 F5–206。

英文字体使用 Arial / Helvetica / sans-serif。中文字幕可使用本地 `ReplicaTitle`，缺失时回退 PingFang SC / Arial / sans-serif；`Fonts` 捕获加载失败，公共包不分发本机字体。字体替代会影响字形与精细字距。
