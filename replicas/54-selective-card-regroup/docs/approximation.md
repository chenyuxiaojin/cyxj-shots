# 忠实度与近似边界

已提取原片全部 396 帧为直接 RGB PNG，对标签轨迹进行逐帧测量，并人工核查关键运动窗口与 32 个对照相位。共享卡片尺寸为 202×304（960×540 测量空间），圆角约 13。可见标签的 SIFT 相似变换、紫色轮廓拟合与少量被遮挡阶段的人工外缘锚点共同确定位置及角度。

保留的核心运动：参考单卡升起、七张扇形展开、两张向右保留、其余五张沿底部枢轴收拢、AUDIO → ANGLE → KEY VISUALS → TOPIC 的换顶顺序、两组合并与新顺序展开。右侧两张 F145–236 锁定；全部卡片 F272–395 几何锁定。没有额外镜头缩放或周期摆动。

有明确近似的部分：

- 源片的紫黑背景、边缘光晕、卡片渐变与光圈内部光色以程序渐变近似；没有整幅贴图。光圈出现时按来源淡入，合并期间改变中心与半径，稳定段不添加周期扫光。
- 标签暂时被遮挡或快速洗牌产生模糊时，使用可见卡片边缘锚点与插值；隐藏的底层卡片错层无法从单目视频完全确定。
- 源片运动模糊的快门参数不可知；本实现仅对正在运动的卡片施加随速度变化的定向模糊，保留的两张保持清晰。开头已有的残影以竖向模糊近似。
- 系统字体近似原字体；卡片标题字号、双语字幕宽度依据源片调整，但不宣称字形像素一致。
- 七张卡、两张保留卡是本镜头的结构约束。变体可换索引和顺序，不将卡片数量扩展为任意数量。

源片画面中的持续微弱色彩噪点不解释为几何运动。所有近似均保留为可编辑元素。
