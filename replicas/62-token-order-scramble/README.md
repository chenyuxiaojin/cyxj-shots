# 字块选中 · 光标扫选与整板推近

带边框的两行字块渐显，鼠标从右侧移入；部分字块依次变黄，随后取消选中并整体推近。字序是静态内容，原片没有字块重排。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

参数入口：`props.json`。

- `title`：可编辑的内容或显示配置。
- `lines`：可编辑的内容或显示配置。
- `captions`：可编辑的内容或显示配置。
- `background`：可编辑的内容或显示配置。
- `ink`：可编辑的内容或显示配置。
- `accent`：可编辑的内容或显示配置。
- `showCaptions`：可编辑的内容或显示配置。
- `durationSeconds`：总时长，秒；全部关键帧按比例缩放。

两行字块、光标进入、逐项选中/反向取消和整板推近均用原生 SVG 和文字实现。字序保持静态，原片没有重排动作。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
