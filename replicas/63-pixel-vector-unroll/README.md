# 像素展开 · 二维矩阵到一维向量

28×28像素阵列先撤去尺寸括号，逐行错开拉伸，再铺成一条水平向量，最后压缩为省略号表示并加上784总量括号。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

参数入口：`props.json`。

- `title`：可编辑的内容或显示配置。
- `pixelRows`：可编辑的内容或显示配置。
- `credit`：可编辑的内容或显示配置。
- `captions`：可编辑的内容或显示配置。
- `background`：可编辑的内容或显示配置。
- `ink`：可编辑的内容或显示配置。
- `accent`：可编辑的内容或显示配置。
- `showCaptions`：可编辑的内容或显示配置。
- `durationSeconds`：总时长，秒；全部关键帧按比例缩放。

28×28 圆点、矩阵尺寸标注、行间拉开与横向展开、向量省略号和括号均为原生 SVG。pixelRows 中每个十六进制字符控制对应像素亮度。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
