# 字阵扩散 · 推近聚焦与中心点亮

字阵由少量行扩展为整块矩阵，标题向上让位；镜头推近标题后拉回，中心字块开始以波形向四周逐圈点亮。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

参数入口：`props.json`。

- `title`：可编辑的内容或显示配置。
- `heading`：可编辑的内容或显示配置。
- `subheading`：可编辑的内容或显示配置。
- `text`：可编辑的内容或显示配置。
- `captions`：可编辑的内容或显示配置。
- `background`：可编辑的内容或显示配置。
- `ink`：可编辑的内容或显示配置。
- `accent`：可编辑的内容或显示配置。
- `showCaptions`：可编辑的内容或显示配置。
- `durationSeconds`：总时长，秒；全部关键帧按比例缩放。

24×8 字阵、上方标题卡、镜头推近/拉回及中心向两侧扩散点亮均为原生文字和 SVG。文字、标题、副标题、字幕、色彩及总时长可改。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
