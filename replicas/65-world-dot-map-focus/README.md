# 地图巡航 · 点阵区域切换与标签揭示

点阵地图从东南亚横移至拉美，再移动到欧洲，叠加中英文地名；红色短标签逐字揭示。地图由可编辑圆点坐标绘制，区域色、文字和时长均可改。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

点阵是原生SVG圆点/六角点；中心从三张参考帧的色块测量后保存为dots。地名、英文、标题、角标和字幕均为文字。

参数入口为 `props.json`，时间使用 `durationSeconds` 等比例缩放。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
