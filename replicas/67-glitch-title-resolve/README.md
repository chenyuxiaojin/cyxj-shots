# 故障字标 · 横向切片与色道收束

断裂字母和白色扫描块聚合为英文；中文字标出现后经历RGB纵向错位、横向切片和扫描线，最终稳定。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

实现范围：原生SVG文字、横向裁切、色道错位与扫描块；所有文案仍为文字参数。

近似差异：原片为专门设计的差评字标，使用可编辑粗体文字近似；RGB裂纹与英文扭曲采用确定性切片，未逐像素重建原片噪声。品牌角标与原声不包含。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
