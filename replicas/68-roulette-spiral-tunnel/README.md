# 轮盘隧道 · 螺旋缩放与金字显影

红黑轮盘卷成连续螺旋，镜头拉远露出多圈带面；旋转继续，金色主标题由碎片显影，副标题依次出现并锁定。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

实现范围：原生SVG连续螺旋、多边形红黑格、数字、金边、镜头缩放、文字遮罩。

近似差异：轮盘按平面阿基米德螺旋重建；原片有立体金属材质、景深、复杂反光及非均匀透视，这些以渐变近似。金字使用可编辑字体及块状显影，非原片纹理字。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
