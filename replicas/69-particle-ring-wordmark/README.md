# 粒子字标 · 星点成环与字母融合

散落的发光粒子收拢为圆环，圆环逐渐实体化成字母O；镜头缩回显示完整字标，并在结尾画出蓝色短线。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

实现范围：固定种子的原生圆点粒子、环形收拢、实体圆环、文字和下划线；没有参考电影或照片。

近似差异：粒子为二维发光点，原片的3D闪烁、镜头颗粒与标志字体有差异。移除前一发布会镜头的残留叠化和来源角标，直接从暗底粒子开始。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
