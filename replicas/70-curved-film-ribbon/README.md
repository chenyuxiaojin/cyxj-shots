# 曲面影带 · 弧形展屏与图片巡游

夜景建筑上展开一条向右上方弯曲的影带；图片在曲面内持续右移，金边随带面弯曲。背景、图片、曲率、速度、字幕与时长均可替换。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

实现范围：背景和7张面板为原参考局部静态资产；弯曲、金边、展开、滚动、字幕全部由SVG和逐帧参数控制。

近似差异：原片面板内部的视频替换为可更换静态裁片；拉直后再逐列弯曲，低分辨率素材局部会变形。背景冻结并移除烧录字幕区域。图片排序和接缝速度按测量值近似；曲面已锁定后仅图片巡游。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
