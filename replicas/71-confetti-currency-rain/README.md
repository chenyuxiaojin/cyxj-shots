# 粒子飘落 · 筹码与纸片翻转

金色筹码浮雕作底，远近不同的圆形筹码与可弯曲纸片持续落下，纸片翻转、旋转、横向摆动，密度逐渐增长。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

实现范围：原生SVG筹码、通用100数字纸片、纸片弯曲、翻转、深度尺度、横摆和循环发射，固定随机种子。

近似差异：筹码与纸片使用程序形状，未使用真实货币扫描图。原片纸张柔体、货币纹理、景深与粒子逐个路径无法恢复，采用同类运动模型近似；金色背景用几何浮雕与噪声替代原纹理。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
