# 图标漩涡 · 旋转隧道收拢成展屏

大量应用方块围成纵深旋转隧道，向中央展屏收拢；舞台灯光和矩形图标墙随之显现。参考窗口只有17帧，原速0.68秒，可修改时长放慢使用。

```sh
npm ci
npm run dev
npm run check
npm run preview
```

在 props.json 修改文字、数值、配色和 durationSeconds。结构/轨迹见 src/Scene.tsx，来源与近似见 docs。静态参考资产如有保留，其权利属于原权利人，代码许可不涵盖这些资产。原片不包含在公开包内。

实现范围：固定种子的原生方块图标、可编辑符号、纵深漩涡、分散收拢、展屏轮廓和舞台光束。

近似差异：使用通用图标取代原应用商标；原片的实际舞台摄影与运动模糊用原生形状近似。源窗口仅17帧，收尾仍是过渡；未添加虚构保持段。开头上一镜头残影被省略。

发布包不分发本机字体。字体配置与回退见组件和资产说明；缺失字体时字形、字宽可能与预览略有差别。需要精准匹配时请使用自己有权使用的字体。
